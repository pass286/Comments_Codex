## 我的学习理念

> 编程不是"学"会的，是"做"会的。

看了 100 小时的教程不如亲手敲 10 个小项目。复盘总结比盲目刷课更重要。

## 学习路线

### 第一阶段：打好基础（1-3 个月）

- 选一门语言深入（推荐 Python 或 JavaScript）
- 理解变量、循环、函数、面向对象
- 用 LeetCode 简单题巩固语法

### 第二阶段：动手做项目（3-6 个月）

- 个人博客 / Todo App / 爬虫
- 学会 Git 版本控制
- 学会用搜索引擎和官方文档

### 第三阶段：深入底层（6-12 个月）

- 计算机网络（HTTP、TCP/IP）
- 操作系统基础（进程、内存、文件系统）
- 数据库（MySQL + Redis）
- 数据结构与算法

### 第四阶段：工程化思维

- 设计模式
- 系统设计
- 代码质量与重构
- 团队协作与 Code Review

## 每日习惯

```markdown
- [ ] 写 50 行代码（至少）
- [ ] 读 30 分钟技术文章
- [ ] 记录一个知识点（写博客）
- [ ] 复盘今天的收获
```

## 小结

> 慢就是快。打好基础，做好笔记，保持热情。编程是一场马拉松，不是百米冲刺。
