## 为什么用 Markdown

Markdown 是一种轻量级标记语言，用纯文本就能写出格式丰富的文档。GitHub、Hexo、Notion 都支持。

## 基础语法

```markdown
# 一级标题
## 二级标题
### 三级标题

**加粗**  *斜体*  ~~删除线~~

[链接](https://example.com)
![图片](image.png)

> 这是一段引用
```

## 表格

```markdown
| 姓名 | 年龄 | 职业 |
|------|------|------|
| 张三 | 25 | 工程师 |
| 李四 | 30 | 设计师 |
```

效果：

| 姓名 | 年龄 | 职业 |
|------|------|------|
| 张三 | 25 | 工程师 |
| 李四 | 30 | 设计师 |

## 列表

```markdown
- 无序列表项 1
- 无序列表项 2
  - 嵌套列表

1. 有序列表项 1
2. 有序列表项 2
```

## 任务列表

```markdown
- [x] 已完成任务
- [ ] 待办任务
- [ ] 另一个待办
```

## 分隔线

用三个或以上的 `-`、`*`、`_`：

---

## 常用技巧

- 用 `<!-- -->` 写注释，不会渲染出来
- 用 `` ` `` 包裹行内代码
- 标题后空一格再写内容更规范

## 小结

> Markdown 的核心哲学：**用最简单的语法，专注于内容本身**。
